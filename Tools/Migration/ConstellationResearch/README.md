# Constellation research artifacts

This development-only tool archives source-bound constellation table and current-public behavior. See [the evidence report](../../../Documentation/Migration/ConstellationCorpusEvidence.md) for frames, complete partition counts, original exact-parity failures, matched-build diagnostics, and scientific limits.

`protocol.json` was committed before collection. `Artifacts/` and `AcquisitionTools/` retain the initial experiment unchanged. `DerivedEvidence/` and `DerivationTools/` retain the later compound compiler-condition diagnostic on identical inputs. The final checker has separate provenance in `validation-provenance.json`. Original tool sources are stored as text, rather than executable production or package sources. The C adapter includes authenticated oracle source only in a temporary build; the Swift executable uses the current public API in an isolated package.

Run `python3 Scripts/migration/constellation-corpus.py check` from the repository root for authenticated offline replay. The oracle revision must be available locally; `git fetch --no-tags --depth=1 origin cdb533dbe85c76b39a958ca92f9155d8bd55b392` materializes it when necessary. Replay uses the existing frozen C flags for both C compilations and retains transformed-boundary categorical changes separately from interior/direct regressions. It does not qualify independent physical accuracy or define future native behavior.
