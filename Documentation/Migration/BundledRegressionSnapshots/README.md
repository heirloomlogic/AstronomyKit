# Bundled model regression snapshots, version 1

These are production repeatability fixtures for `bundled-de440-pluto-center-v1`, captured on macOS arm64 after the immutable Moon/Pluto model was integrated. They are not independent astronomical accuracy evidence and assign no direct-rate accuracy allowance. The independent reference samples, original diagnostic archive, historical error budgets, and all assertion tolerances remain unchanged.

`ReproducibilityTests.pre-bundle.swift.txt` preserves the original regression source from commit `ec134360`. The manifest records the 67 deliberately changed Moon/Pluto literal occurrences, their old and new values, and the evaluated production source hashes. Other bodies retain their original expectations. The Moon rate budgets remain 5e-7 degrees/day and 1e-10 AU/day; the other angular, distance, rate, and event replay budgets are unchanged.

`range-rates-v1.json` contains 795 Moon/Pluto records at exactly the original diagnostic epochs and modes: 265 Moon geocentric, 265 Pluto geocentric, and 265 Pluto heliocentric. The test continues to replay all other bodies directly against `range-rate-investigation.json`, and uses this separately versioned fixture for the replaced models with the same 1e-12 AU/TT-day replay tolerance. The original 5,035-row reference projection and unit checks still run against the immutable historical archive.

The two capture source files preserve the temporary instrumentation used to collect these fixtures. The Swift source was temporarily compiled as a test target file; the Python source temporarily added literal capture prints to the pre-bundle reproduction test. Both capture helpers were removed from the active tests after freezing the results. Their output is recorded in the manifest and current fixtures, and automatic test execution never regenerates expectations. Any future intentional model replacement must receive a new explicit snapshot version and preserve this history.
