# Ascending search repair

`Search.findRoot` documents a negative-to-nonnegative crossing. The inherited C solver could return a descending interpolated root or a midpoint in a short constant window. Both reported public failures reproduced under Espenak–Meeus and JPL Horizons before repair; the retained pre-fix test run recorded 100 failed assertions across the direction/constant matrix and exact reports.

Both success paths now require chronologically ordered endpoint callback signs that establish an ascending bracket, with at least one strict sign. Quadratic acceptance also requires a positive fitted derivative; that derivative does not substitute for callback evidence. Reversed ordinary windows retain their observed ascending interpolated result. An unbracketed outer interval still evaluates its midpoint and can select an ascending subinterval. The existing single-root assumption remains; these tests do not promise discovery of every crossing in a window containing several roots. Tolerance arithmetic, captured Delta-T propagation, callback errors and the iteration limit remain unchanged.
