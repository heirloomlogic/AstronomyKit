AstronomyKit lunar coefficient data

This derived coefficient array was generated by Heirloom Logic from NASA/JPL planetary and lunar ephemeris DE440s, integrated 25 June 2020. Heirloom Logic is responsible for the subtraction, unit conversion, coefficient selection, serialization, and integration in AstronomyKit. The derived array is not an official JPL SPK kernel. Original kernel producer attribution is retained as source provenance in moon-de440-source-comments.txt.
