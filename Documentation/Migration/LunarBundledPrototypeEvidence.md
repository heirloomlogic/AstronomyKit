## Native integration and local costs

The reusable folded payload remains 6,581,696 bytes (6.28 MiB). The separate executable combines the previously checked Swift Float64 coefficient/analytic-derivative evaluator with thirteen source-pinned ERFA C routines for approximate geocentric TT-to-TDB and IAU2006 mean-date ecliptic transformation. The [official byte lock](integrated-lunar-erfa-source-lock.json) binds sixteen license/header/C files at ERFA 2.0.1 commit `9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3`; cached or downloaded byte mismatches fail before compilation. The build manifest hashes source, extracted evaluator, objects, executable and compiler commands. These C files are development tooling in ignored scratch, not a shipping dependency or an all-Swift time/frame port.

The geocentric use and explicit TT input follow the [pinned ERFA time-conversion documentation](https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/dtdb.c); the date-plane observable follows the [pinned IAU2006 transform](https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/ecm06.c). Native time/frame values also match the separately loaded pinned Python reference evaluator at the sampled dates. Position derivatives are km per TDB day; the apsis zero uses their positive time reparameterization, and node roots use the TT date-plane position directly. No future civil UTC conversion is claimed.

Five local warm sequential trials of 100,000 states each measured a median **4.88358 microseconds per state**, including coefficient position/derivative evaluation, TT/TDB conversion and the date-plane transform. Median mapping/header/full coefficient-validation time was **1.10571 milliseconds**. Total peak process RSS was **12,582,912–12,615,680 bytes**, approximately **12.0 MiB**. This is process memory, not an exact payload allocation or app installation/download size. The prior bare-coefficient measurement of about 0.12 microsecond excludes TT/frame work and is a different workload.

These observations exclude JSON I/O, event searches, public AstronomyKit API integration, mixed workloads, concurrent queries and Linux/device behavior. There is no owner-selected local microbenchmark acceptance threshold, and this does not satisfy #83's unchanged performance gates. Deterministic report `check` replays source/binary/plan/raw-reference/numerical fields; it retains nonrepeatable archived cost trials rather than reporting them as freshly reproduced timings.
