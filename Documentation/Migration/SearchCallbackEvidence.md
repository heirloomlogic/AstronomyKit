# Finite callback transcript evidence

This investigation prepares source-bound legacy search and light-time evidence for [#84](https://github.com/heirloomlogic/AstronomyKit/issues/84). The retained original population has 51 cases under both captured Delta-T models and both locked-C/current-public backends: 204 fresh processes. A separately selected two-case light-time supplement adds eight processes. The Apple acquisition has zero normalized C/public differences in each population. These are finite observations of existing code; native implementation remains gated by #83 and #84 remains open.

The prospective original protocol was committed at `fb6593186068564da917d0a5cafd9a91035198b3`, before probes. Its source base is reviewed PR141 at `97fc275f6fd455ed73063a6961698569783dddb8`. Original adapters and collector were committed at `5805e024861454b173bdbeb627320c63b2956054`. The first 204-process attempt completed, but assessment rejected public error descriptions because the validator expected enum spellings. Its raw packets existed only in memory and were lost before persistence; they cannot be claimed retained. `FailedAttempts/` preserves that failure log, source snapshots and explicit receipt. Prospective amendment `478fea15da86a4df5869fdb4230bd0fcfc1a37b1` corrected the existing description mapping and persisted raw streams before assessment. The unchanged cases were then collected successfully. No formula, model, source, cap, tolerance or normalization rule was adjusted to obtain parity.

## Cases and observables

The original 32 root cases cover ascending/descending functions, absent roots, both endpoints, quadratic interpolation, multiple roots, a flat cubic, a step, tolerance variants, reversed/equal/short windows, nonfinite/extreme inputs, representational stalls, selected callback errors and a research cap. The 19 light-time cases cover constant/moving vectors, zero/negative/nonfinite/extreme vectors, supplied vector timestamps, one-light-day range neighbors, invalid/extreme times, selected errors and nominal alternating/cap probes. All frozen cases and observed outcomes remain in the archive.

Times are UT and TT days since J2000. Each initial time explicitly captures Espenak/Meeus or JPL Horizons, then derives endpoints through `addingDays`. Every callback invokes the process-default setter, requesting the opposite model on odd visits and the initial model on even visits. `defaultBefore` and `defaultAfter` record the adapter's selection ledger; received model identity, UT, TT and separately constructed captured-model TT are recorded from the actual time values. This does not test concurrent process-default mutation or arbitrary custom Delta-T functions.

Each raw JSONL stream contains a begin event, ordered callback visit/time/model/default/result events and either a terminal event or research-cap event. Finite scalars use exact binary64 bit strings; NaN and infinities use explicit tags. Callback vectors retain their supplied timestamp. Final records retain C status or the public error/sentinel, first error visit, callback count, time and vector when present. The wrapper's SEARCH_FAILURE-to-nil and chosen-error rethrow are normalized explicitly. Algorithm error categories map their existing C statuses to existing public descriptions. The public position trampoline replaces the supplied vector timestamp with callback time; only this declared final timestamp difference is normalized. Raw C and public timestamps remain available.

The ordinary research callback cap is 128 and each fresh process has a five-second timeout. The two original cap-labelled cases use cap two. A cap or timeout is research termination, separate from algorithm success/failure and from any product budget. A directed subprocess timeout test retains partial stdout; none of the retained normal acquisitions timed out.

The original alternating vector starts at zero distance and converges on its first visit. Thus `light-nonconvergent` and `light-research-cap` are historical selection labels whose intended branches were not exercised; their successful outputs remain unchanged. Supplement protocol `5cc05267558d120fea033a021e982af291af0331` was committed before execution. Its two requests reuse the unchanged moving fixture with `[1,100,0,0]`, caps 128 and two respectively. Both models/backends produce ten-visit nonconvergence with finite vectors inside the one-light-day limit, and research termination at attempted visit three. Original and supplemental populations are separate; no original request was replaced.

Some legacy outcomes are representation/model sensitive. The lower-endpoint root is absent under Espenak/Meeus and returned under Horizons. The extreme-time and representational-stall outcomes also differ between models. The descending linear case returns a value, and a positive constant in the short window returns a value without an ascending crossing. These inherited production false positives are tracked in [#142](https://github.com/heirloomlogic/AstronomyKit/issues/142), with their finite reproductions and user impact. #84’s direction/absence criteria govern its future native-port tests and do not explicitly own the production repair. The research preserves the wrong outcomes as evidence; parity does not make them correct or establish future compatibility requirements.

The solvers, fixtures and public wrapper share the vendored engine, so this is migration evidence rather than independent scientific accuracy. Generic callback traces include deliberately nonphysical times and vectors. Within-platform assessment compares complete ordered packets and declared normalized outcomes. Cross-platform replay uses the prospectively frozen `1e-8` day time and `1e-12` scalar/vector envelopes, with unchanged categorical, order, model and outcome requirements. Those are experiment controls, not physical uncertainty bounds, whole-domain accuracy evidence or a new release gate. Counts and branches describe these finite inputs, not universal call-count guarantees. Both development C compilations use the entire existing locked flag set; no unique compiler-setting cause is inferred.
