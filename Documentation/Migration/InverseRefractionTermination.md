# Inverse refraction termination

`Refraction.inverseRefractionAngle(at:)` returns zero correction for a nonfinite or out-of-range altitude, or when the inverse iteration cannot converge. `Vector3D.from(horizon:at:refraction:)` uses the same C function, so it also returns instead of blocking on these inputs. A zero correction leaves the supplied apparent altitude unchanged; it does not establish that the altitude has a physically accurate inverse. Nonfinite horizontal coordinates can still produce nonfinite vector components, and the wrapper retains the supplied time.

The shared C loop preserves its residual expression, evaluation order and strict `fabs(diff) < 1e-14` convergence comparison. It returns zero on a nonfinite residual or next iterate, a representational stall, a two-state cycle wider than adjacent doubles, or exhaustion of 1,000 iterations. A wider cycle spans the jump at the forward model's range boundary, where refraction drops to zero and no altitude in range refracts to the input; NaN kept the old convergence comparison false indefinitely. A two-state cycle between adjacent doubles returns the correction to the lower one. Below -1 degree, altitude plus normal-mode refraction rises about 1.007 times as fast as altitude, so its rounded value skips some doubles. From magnitude 64 the spacing of doubles (1.42e-14) exceeds the tolerance, and the two neighbors of a skipped altitude alternate, each refracting to one ulp from it. The forward refraction model is unchanged. This is local patch 21 in [MAINTAINING.md](../../MAINTAINING.md), tracked by [#147](https://github.com/heirloomlogic/AstronomyKit/issues/147).

The base loop alternated forever on those skipped altitudes, and `ca7b075b` returned zero for them, so the horizontal vector was off by the full correction: up to about 0.19 degrees near -64. A Swift regression sweeps 200,000 evenly spaced normal-mode altitudes in [-90, -64) and requires an inverse within one ulp; 1,396 failed before the straddle repair. In jplHorizons mode, apparent altitudes from -90 to -89.3534 still return zero: every altitude in range refracts to -89.3534 or higher, so none refracts to them.
