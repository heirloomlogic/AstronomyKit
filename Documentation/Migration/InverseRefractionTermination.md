# Inverse refraction termination

`Refraction.inverseRefractionAngle(at:)` returns zero correction for a nonfinite or out-of-range altitude, or when the inverse iteration cannot converge. `Vector3D.from(horizon:at:refraction:)` uses the same C function, so it also returns instead of blocking on these inputs. A zero correction leaves the supplied apparent altitude unchanged; it does not establish that the altitude has a physically accurate inverse. Nonfinite horizontal coordinates can still produce nonfinite vector components, and the wrapper retains the supplied time.

The shared C loop preserves its residual expression, evaluation order and strict `fabs(diff) < 1e-14` convergence comparison. It returns zero on a nonfinite residual or next iterate, a representational stall, a two-state cycle, or exhaustion of 1,000 iterations. The forward refraction model is unchanged. Near its range boundary the inverse can alternate between two altitudes; NaN kept the old convergence comparison false indefinitely. This is local patch 21 in [MAINTAINING.md](../../MAINTAINING.md), tracked by [#147](https://github.com/heirloomlogic/AstronomyKit/issues/147).

The [prospective protocol](inverse-refraction-147-protocol.json) and disposable public probe were committed at `1ecff3a233206362e2c47b2b86114a2d28f15cdb` before acquisition or production edits. Its 26 altitudes include NaN, infinities, ±91, exact ±90, adjacent doubles, interior endpoint offsets of approximately 1e-12, 1e-6, 1e-3 and 1 degree, and finite interiors. Three refraction modes, both public routes and both captured Delta T models make 312 fresh processes per revision. The direct correction has no time dependence; the model controls exercise the supplied time on the horizontal route. Each child has a one-second research cap and is killed and reaped if necessary. This cap is not a public timing guarantee.
